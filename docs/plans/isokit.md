Decided: name isokit · GitHub public · GitHub Pages from main · site in English.

- `skill/`: SKILL.md, recipes.md, lib, scripts, and examples written new for this repo (fictional products only).
- `site/`: Astro, static, scenes rendered at build with `skill/lib`.
- Never in the repo: `skill/reference/` (git-ignored) or any third-party scene, logo or name.
- `~/.claude/skills/iso` becomes a link to this repo's `skill/` once the owner switches over.
